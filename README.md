Проект: Социальная сеть

Описание: Данный проект является мини-приложением, созданным в учебных целях для тренировки навыков работы с CRUD-операциями и backend стеком.

Возможности: 
- Регистрация и аутентификация пользователя.
- Подгрузка из backend и просмотр ленты постов.
- Создание нового поста.
- Редактирование поста.
- Шаринг поста.
- Удаление поста.

Проект написан на Kotlin с использованием XML для разметки. В качестве API использован учебный сервер.
Применены следующие основные технологии:
- Fragment;
- Data-classes;
- Adapter;
- ViewModel;
- Repository;
- API;
- Shared preferences;
- Room;
- DAO;
- MVVM;
- Dagger Hilt;
- Remote Mediator.
